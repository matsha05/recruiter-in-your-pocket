Four ways to set one entry

The same two entries from the bad resume (Shift Lead, line 1; the dates), the same content, four typographic treatments. D follows the brief (typography-brief.md); A to C were the first round. The score, the bands and the write-up above the list stay as they are. Phone follows each one as a single column.

D. One hand for the resume, before and after

From the brief: the quoted line and the example are the same thing, the resume before and after, so they share one face, one size and one left edge, and read as a diff. The recruiter's query sits between them, small, in the sans. The note is marginalia in the pen, no rule, beside the line it comments on. Color only in the text: the marker, the blue blanks, the pen. 48px between entries.

A. Two voices, held apart

Serif only where someone is speaking: the resume's line on its paper, the recruiter's note in the pen. Everything else is the sans. The new line sits on a quiet inset in the sans, the way the sketch Matt chose drew it, so the three serif blocks never stack. Label in uppercase pen. Entries 2.5rem apart, no rules inside an entry.

B. The numbered ledger

A light Literata numeral anchors each entry, so the page has a rhythm you can count. Two colors inside an entry, not four: the marker on the line and the blue in the blanks; the note is ink italic, and the pen green is kept for the write-up and the keep tick. The example is the largest text in the entry, the thing you came for. 3rem between entries.

C. Margin notes

The resume is the page: the clipping runs wide and the recruiter's note sits beside it in the margin, as it would on paper. The new line follows the clipping underneath, on the highlighter's soft tint, so each entry reads top to bottom as before and after, the Lifted Line. The question is the caption above it.
