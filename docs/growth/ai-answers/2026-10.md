## Method

These are **API runs with web search**, not the consumer ChatGPT or Perplexity apps. Source: live APIs. OpenAI Responses model: `gpt-6-astra`; one fresh request per prompt, prompt text verbatim, no system prompt or conversation history. Web search is required, low search context, at most one hosted tool call, low reasoning effort, 1536 maximum output tokens. Limits and model versions affect answers; incomplete answers are marked unknown in the count.

A separate `gpt-6.1-terra` no-search API pass extracts metadata from each saved answer. It does not re-ask the prompt. Tool names are checked against the answer, and evidence quotes against the answer or a cited page title; cited URLs are taken directly from API annotations in answer order (duplicates preserved). Summaries are machine-generated and should be reviewed with the raw answers. RIYP matching checks the brand name or its domain in the answer/citations.

- **Perplexity API:** Disabled at owner request: paid API; no calls made.
- **Consumer ChatGPT, Perplexity, Claude, and Google AI Mode:** Not measured by this API job; by-hand reads remain separate. Google AI Mode and consumer-app answers have no equivalent API.
