# What a sharp recruiter would lead with, per case

Written from the resumes alone, before reading the model's output for that case (two exceptions: `h2_thin_resume` run 1 and `h6_unverifiable_claim` run 1 had already run as the pilot; their leads below were still written from the resume). "Lead" is the first thing the friend across the coffee says; "then" is what comes next. The audit's tables mark each run against this file as led, buried (said, but not first or not on the first screen), missed, or impossible (not knowable from the text).

## Holes

| Case | Lead | Then |
| --- | --- | --- |
| h1_bad_resume | "This resume is for a Marketing Manager job and nothing on it is marketing. Who is this for?" | Five jobs in four years, two with no dates; nothing since June 2023; the objective and the skills list are filler; "employes", "saftey", "manor" are typos a screener will see; every bullet is a duty.
